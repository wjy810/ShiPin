# 风格 A · 野外记录本：全片统一规则

样图在仓库 `样图/style-a/`。这一页是从《这道题的答案，一直在变》里定下、并在成片里验证过的规则。新片子沿用，除非用户另给风格。

## 目录

1. 一条总原则
2. 纸面、颜色、字、版式
3. 图片处理（A1–A5、B）
4. 常驻元素（小钟、问号）
5. 动作词汇

7. 不做的事

## 1. 一条总原则

**真实照片 = 证据，做成贴在本子上的冲印照片；示意 = 墨线手绘，盖「示意」章。**
观众一眼分得出哪些是拍到的、哪些是画出来的。科普片讲“结论来自证据”，画面本身就得守这条。
所以：示意图不用照片质感；照片上不画东西，除非找图.md 允许（只许加圈的，就只加圈不加字）；**位置核实不了就不圈**，换成在字上强调，或者用慢推把视线带过去。

## 2. 纸面、颜色、字、版式

| 项 | 值 |
|---|---|
| 纸 | `#F1EBDD`；横格线每 55 px 一条，墨色 13% 不透明；固定种子生成的纸纹平铺；左边三个活页孔 |
| 墨（主字、墨线） | `#23201A` |
| 锈红（强调） | `#9A3412`，**每屏最多一组** |
| 铅灰（过时的、被修正的） | `#635D53`，在纸色上对比度 5.48:1。只给旧答案、被推翻的结论用 |
| 相纸白 | `#FBF8F1` |
| 胶带 | `#D8C39A`，88% 不透明 |
| 桌面（只在整页拉远时露出） | `#CFC6B2` |
| 字体 | 思源宋体（Noto Serif SC）900；只含片中用字的子集，章上的字也要在子集里 |
| 字号 | 主字 96–100 px，时间大字 110–120 px，最小 72 px；字距 −0.02em，行高 1.2 |
| 版式 | 最多两行、左对齐，默认左下（左 120、下 118）。**不放画面正中**（文案写“居中”的也改成左对齐，在分镜里写明理由） |
| 安全区 | 字、照片、钟离四边至少 96 px |

## 3. 图片处理（不直接贴图）

| 代号 | 做法 | 适用 |
|---|---|---|
| A1 相纸冲印 | 照片外加 20 px 相纸白边，投影 `0 18px 44px rgba(35,32,26,.28)`，倾斜 1.5–2.5°（每屏方向交替），上沿两条胶带。像素层用烤好的相纸调色（`assets/print-grading.json`：vintage-wash，intensity 0.5，颗粒 0.08，暗角 0.08），只要静态部分，不闪不晃 | 大多数实物、化石、野外照片 |
| A1（不调色） | 同上，像素不动 | 颜色本身有含义的图（比如用颜色表示海拔的地形图） |
| A2 论文剪报 | 从论文图的深色底里只取照片本身；白边 12 px，墨线回形针代替胶带 | 论文配图 |
| A3 圆形贴片 | 沿圆形主体裁圆、去黑底；10 px 白边，一条胶带；不调色 | 地球这类圆形主体，可以缩进钟心 |
| A4 去底拼贴 | `mix-blend-mode: multiply` 叠在纸上，白底自然变纸色，不抠图、不改内容 | 白底的复原图、插图；必须标「复原图」之类的章 |
| A5 竖幅相片 | 用竖幅原始裁切，别用带深色底的横版；其余同 A1 | 竖拍的露头、剖面 |
| B 墨线示意 | SVG 手绘线，墨色 5–6 px、圆头；强调用锈红；描线动画画出来；角上盖「示意」章（锈红 4 px 方框，40 px 字，倾斜 −4°，背景相纸白 85%） | 时间轴、钟、岩层、剪影、地图、条形图、天平…… |

烤之前先裁：只要照片本身（不要论文图的深色底、展台），≤ 1920×1080。每张图做一组处理前/处理后对比，处理后不比原图好就保留原图。

## 4. 常驻元素（小钟、问号）

这次全片有一个“24 小时钟”贯穿（34.3 亿年压成一天），做法可以照搬到任何“时间尺度”类的片子：

- 钟面：墨线圆 6 px，24 根刻度（0/6/12/18 点四根加长），锈红指针 5 px 圆头，中心一个铆钉。**表盘上不写字**。0 点在正上方。
- 三个位置：中间（直径 520，介绍时）→ 右上角常驻（直径 168–144）→ 时间跳转时放大到右侧中部（直径 420），下一屏缩回去。
- 指针角度一律按文案里的换算算式算，写进分镜的表里。
- 指针跳格 = 每格 3 帧急停（power4.out）+ 一下滴答声。
- 一个锈红手写问号从“争议”出现起常驻在钟旁边，片尾飞进最后一句，落成“证据呢？”的问号。

## 5. 动作词汇（30 fps）

| 动作 | 做法 |
|---|---|
| 照片卡弹出 | 0 倍 → 原大，10–12 帧，power3.out，不回弹 |
| 贴胶带 | scaleX 0→1，7 帧，第二条晚 2 帧 |
| 急停落字 | 透明度直接切 1（不淡入），从下方 45–80 px 落到位，5–6 帧，power4.out；几组字错开 1 帧或半拍 |
| 甩出 | 向上 80 px、转 ±5°，6 帧，第 5 帧透明度直接切 0 |
| 描线（下划线、圈、括号、箭头、问号） | SVG 路径描出，匀速，默认 1 拍；锈红 9 px 圆头 |
| 虚线“描”出来 | 虚线本身不动，用遮罩里的一条实线按长度画出（见 hyperframes-patterns.md） |
| 盖章 | 1.35 倍压到原大，4 帧，透明度直接切 |
| 推页 | 整页平移 1920 px，8 帧（尾声 12 帧），power4.out，**从切点那一帧开始**，重拍落在推页最猛的那一下；新页元素也从切点开始入场 |
| 反向推页 | 回到“开头那题”时整页从左边推进来，告诉观众“翻回第一页” |
| 指针跳格 | 每格 3 帧急停，power4.out |
| 整页慢推 | 1 → 1.012 左右，整幕匀速，让纸面一直有一点生气 |
| 褪色 | 被推翻的结论换成铅灰（全片唯一允许的渐变之一） |

## 6. 卡拍规则

1. 切点只放在整拍上；幕与幕的切换放在段落（高潮、间奏、重低音段）的第 1 拍。
2. 屏内动作放在拍或半拍上（128 BPM 时半拍 ≈ 7 帧）。分镜表里的“+2”指从本屏第一拍算起第 2 拍，“+2.5”是第 2 拍后半。
3. 字在切点那一帧出现，阅读时间 = 整屏时长。分两次出现的屏，后半句至少留 4 拍。
4. 绝对帧号 = round(全片拍号 × 每拍帧数)。每拍不是整数帧时四舍五入，误差不超过半帧。
5. 音效（滴答、咔嗒）的**最响那一下**落在拍点后约 20 ms，和 3 帧急停的那一下对齐。

## 7. 不做的事

霓虹光效、紫色渐变、字放正中、全靠淡入淡出、照片实时闪烁的颗粒、在照片上写骨骼名称或“真化石”“原件”之类找图.md 禁止的字。全片的渐变只留两处：被推翻结论的褪色、片尾配乐淡出。
