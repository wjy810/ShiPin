# 分镜.md 怎么写

范例：仓库根目录的 `分镜.md`（36 屏，2:06.6）。新片子照它的结构写。写完先停，等用户检查。

## 文件结构

```
---
format: 1920x1080
fps: 30
duration: 126.5625s
message: "一句话讲这支片子要观众带走什么"
arc: 第 1 幕 → 第 2 幕 → … （每幕一个短语）
audience: 目标观众
style: 风格 A · 野外记录本（样图/style-a）
music: bgm.mp3，128 BPM，按段落剪成 2:06.6
---

# 分镜：<片名>

一行规格：风格 ｜ 分辨率 ｜ 帧率 ｜ 总长（秒，帧）｜ 屏数 ｜ 用 HyperFrames 搭建

## 0. 先看这里        ← 用户最该先读的 5–6 条：拍子、总长和理由、配乐怎么剪、图片的统一处理、要拍板的事在哪
## 1. 配乐：拍子、段落和剪辑
### 1.1 拍子怎么找的     ← beat_grid.py 的结果；自动测速错在哪
### 1.2 原曲结构         ← 每段几小节、从几秒开始、听起来像什么
### 1.3 剪辑版           ← 剪辑表（段、全片拍、全片时间、起点帧、原曲小节、media_start、用在哪几屏）+ 每个接口为什么这样接（splice_check.py 的分数）
### 1.4 文案里的音乐提示，和这首曲子对上的情况
## 2. 风格的统一规则      ← 引用 references/style-a.md 的内容，写成这支片子的具体值
## 3. 时间总表           ← 每屏：起点、起点帧、帧数、拍数、时长、文案给的时长、差、音乐位置、转场
## 4. 自查               ← 阅读下限、切点、配乐剪辑实测、格式检查、文字逐字比对、找图.md 的每条限制
### 需要你拍板 / 已定   ← 写完时是“需要你拍板”，用户定了以后改成“已定”并写结果
## 5. 分镜               ← 36 个 Frame
```

## 每屏的格式（HyperFrames storyboard 解析器能读）

```markdown
## Frame 9 — 屏 9 · 第 3 幕 · 37 亿年

- scene: 一句话画面：只有字和钟，钟放大到右侧，跟着滚奏把指针倒拨到 0 点之前
- duration: 2.8125s
- transition_in: cut            ← cut / push-left / push-right / freeze …
- src: compositions/act-3.html  ← 相对 成片/；一幕一个文件，几屏共用
- status: outline               ← outline → built → animated（成片做完全部改成 animated）
- 时间: 0:29.062 – 0:31.875（第 872–955 帧，共 84 帧；全片第 62–67 拍，共 6 拍）
- 音乐: 原曲第几小节第几拍，那里听到什么（滚奏、底鼓抽掉、骤停……）
- 字: 「约37亿年前的／“叠层石”！」（13 字，下限 2.6 秒，实有 2.81 秒）
- 图: 用哪张原图（或“无”，写明原因）
- 图片处理: A1 / A3 / B …（见 style-a.md）
- 转场: 切

| 拍 | 帧 | 动作 |
|---|---|---|
| +0 | 872 | 字落下……；钟飞到右侧中部并放大（6 帧，power3.out） |
| +2 | 900 | 指针每半拍倒跳一格（共 8 跳，每跳 3 帧急停，每跳一下滴答） |
| +2.5 | 907 | 整页随滚奏轻微推近（1→1.03，3.5 拍，power1.in） |

表下面一行写算式或依据（角度怎么算、数字出自哪里、为什么不圈）。
```

- “全片第 a–b 拍”这串字 `endstate_sheet.py` 会读，格式别改。
- 字一字不改地照抄文案，用「」括起，换行用 ／。字数、下限、实有时长三个数都写。
- 动作表的帧号 = round(全片拍号 × 每拍帧数)。

## 时长怎么定

1. 每屏时长 ≥ 字数 ÷ 5 秒，且 ≥ 2 秒（阅读下限）。脚本断言，别靠眼睛。
2. 每屏是整拍数；幕切换落在段落第 1 拍。
3. 总长 = 剪辑版配乐长度，只能按 4 小节加减。和文案对不上时，在第 0 节写清差多少、为什么、要压回去得付出什么代价（低于阅读下限，或在乐句中间硬切）。
4. 余量不到 1 拍的屏列出来——搭建时这些屏的字不能比表里晚出现。

## 检查

```bash
node storyboard_check.mjs 分镜.md 126.5625   # 0 警告、时长合计相等（用法见脚本顶部）
```

## 成片做完以后

把搭建时的改动回写：换掉的圈（核实不了位置）、拆开的幕、加的音效、`src` 指向实际文件、`status: animated`、“需要你拍板”改成“已定”。分镜要和成片一致，别人才能照着改。
