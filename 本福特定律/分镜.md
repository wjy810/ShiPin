# 分镜：Vibe知识大赏 · 偏心的数字（本福特定律）

- 成片：`成片/偏心的数字.mp4`，1920×1080，30 帧/秒，157.5 秒（4725 帧），H.264 + AAC 256k
- 片型：抖音「Vibe知识大赏」——无旁白，画面把知识“演”出来；深色底（`#05060B`）+ 香槟金；衬线字；底部中英双语字幕；心里作答、命名卡（带英文副标）、“示意”标注；结尾片名回归 + 提问，再给文献线索和声明
- 文案和出处：`文案.md`；设计规范：`成片/design.md`

## 1. 配乐和拍子网格

- 原曲：仓库根目录 `bgm.mp3`（用户原创，128 BPM）
- **降速 0.8 倍**（黑胶式，音高跟着降约 3.9 个半音）→ **102.4 BPM**。
  - 为什么是 0.8：原速 128 偏“燃”，抢画面；0.8 倍刚好落到 100 BPM 出头，鼓点还在，但每拍 0.586 秒，够一个数字落定、一行字读完。
  - 再低（0.7 倍）低频开始发浑，旋律也拖。
  - 降速后加了轻混响（RT60 约 2.2 秒，湿声 16%）和 5 kHz 以上 +2.5 dB，补回降速损失的空气感。
- 一拍 T = 60 / 102.4 = **0.5859375 秒**（48 kHz 下正好 28125 个采样），一小节 2.34375 秒。全片第 n 拍从 n×T 开始，所有合成里的 `at(b)` 都是这个拍号。
- 剪辑（全部按降速后的时间）：

| 片中 | 原曲小节 | 内容 |
|---|---|---|
| 0–75.0 秒（片中第 1–32 小节） | 1–32 | 前奏、第一段高潮、间奏、滚奏 |
| 75.0–131.25 秒（第 33–56 小节） | 41–64 | 第二段高潮、重低音段前半 |
| 131.25 秒到片尾（第 57 小节起） | 73 到结尾 | 最终高潮、收尾重音 |

- 两个接口都在小节第 1 拍、和弦轮同一位置（和声相似度 0.990、0.997），淡入淡出各 10 毫秒。
- 最后 2.5 秒平方曲线淡出，让混响自然收掉。
- 实测：降速后起音都落在拍点和半拍上（偏差约 −10 毫秒）；成片和母带零偏差（1、19、76、132、141 秒五处）。

## 4. 音效（全部用 numpy 合成，无外部素材）

## 5. 重做

在 `成片/` 目录下（要有 ffmpeg、numpy、scipy、fontTools + brotli）：

1. `python3 scripts/build_audio.py` → `assets/audio/mix.flac`（同时写一份不带音效的 `music_only.flac`，不进仓库）
2. 改了任何文字：`python3 scripts/fonts.py <NotoSerifSC[wght].ttf>`（重新子集化思源宋体）
3. `npx --yes hyperframes@0.8.169 check`（0 错误）
4. `npx --yes hyperframes@0.8.169 render -q delivery -o renders/render.mp4`（这台机器约 13 分钟）
5. `python3 ../../.claude/skills/notebook-explainer-video/scripts/finalize.py renders/render.mp4 assets/audio/mix.flac 偏心的数字.mp4`
   - HyperFrames 的音频管线会在片头冒一下尖峰，渲染器因此把整条声音压低 7–9 dB；这一步把声音换回母带。
