# design.md — 偏心的数字（Vibe知识大赏 · 夜曲风）

一句话概念：**黑夜里漂浮着全世界的数字，只有“首位”会发金光**——数字既是背景的尘埃，也是每一屏的主角。

## 颜色（只用这些）

| token | 值 | 用途 |
|---|---|---|
| `--bg` | `#05060B` | 底色 |
| `--bg-navy` | `#0D1430` | 光晕、渐变的深蓝 |
| `--ink` | `#F3EEE3` | 主字（暖白） |
| `--ink-2` | `rgba(243,238,227,.66)` | 正文、英文字幕 |
| `--ink-3` | `rgba(243,238,227,.34)` | 注释、水印 |
| `--gold-hi` | `#F7E7BC` | 金色高光 |
| `--gold` | `#D8B46A` | 金色主色：首位数字、关键数字、结构线 |
| `--gold-deep` | `#8E6E35` | 暗金：辅助线、刻度 |
| `--slate` | `#6F7C99` | 反例、“编出来的数”、直觉错误（冷色，和金色对立） |

规则：金色只给“真实的、对的、首位”；冷灰蓝只给“直觉、反例、编造”。每屏金色元素 ≤ 3 处。

## 质感与环境层（全片常驻，见 compositions/bg.html）

- 深蓝到黑的径向底色 + 两团缓慢呼吸的光晕（深蓝在下、暖金在上）
- 数字尘埃：约 200 个 0–9 的字形，三层景深，缓慢上浮；近处的大而淡，远处的小而密
- 极淡的光束从顶部斜下，缓慢转动
- 胶片颗粒（固定种子生成的 PNG）+ 四角暗角

## 动作

- 出场：透明度 0→1 + 上移 18px→0 + 模糊 8px→0，0.6–0.9 s，`power3.out`；重要大字加金属扫光
- 停留：慢漂移（±6px，周期 >8 s）、镜头缓推（1→1.04，整屏）
- 换场：在小节第 1 拍；暗场里用“模糊溶解 + 轻微推近”，关键处用“推进穿过一个数字”（S2→S3、S6→S7）
- 卡拍：重要元素落在拍上，次要的落在半拍；大揭晓（30.1%、片名、31.3%）配低频冲击音
- 不用：弹跳回弹、霓虹、故障闪烁、打字机、emoji、真实照片
