## 改了什么

## 诚实和合规

- 照片质感的图（书房、实验室、鹦鹉螺、计算尺、地球）出现时，右下角都有“AI 示意图”的小标签。

## 生图怎么做的

1. 接口：OpenAI 兼容的 `/v1/images/generations`，模型 `gpt-image-2.5-flare` 和 `gpt-image-2.5-sunburst`。
   - 两个都会忽略请求里的尺寸，按提示词里的比例出图：16:9 出 1672×941，方图出 1254×1254。
   - 密钥只放在环境变量里，不进仓库。
2. 主视觉每张两个模型各出一版，并排看，挑一张。看的是：
   - 有没有乱码文字、畸形结构；
   - 内容对不对得上事实；
   - 黑底干不干净。
3. 提示词原文：`assets/images/ai/prompts-batch1.json`、`prompts-batch2.json`。
4. 处理：`python3 scripts/prep_images.py <原图目录>`。
   - 放大到 1920 宽。
   - 黑底发光的图先压黑位，再按亮度抠成透明 WebP。

为什么要抠图、不直接用 CSS 的滤色（`mix-blend-mode: screen`）：每一场外层都有不透明度和模糊的入场、离场动画，浏览器会把整场隔离成一个独立图层，场景里的滤色只能和本场的内容混合，黑底会露成方框。抠成透明以后用普通叠放，效果和滤色几乎一样。

1. `python3 scripts/build_audio.py`
2. 改了文字：`python3 scripts/fonts.py <NotoSerifSC[wght].ttf>`

4. `npx --yes hyperframes@0.8.169 render -q delivery -o renders/render.mp4`
5. `python3 ../../.claude/skills/notebook-explainer-video/scripts/finalize.py renders/render.mp4 assets/audio/mix.flac renders/master-v4.mp4`
6. `ffmpeg -i renders/master-v4.mp4 -map 0:v -map 0:a -c:v libx264 -preset slow -crf 20 -profile:v high -pix_fmt yuv420p -movflags +faststart -c:a copy 偏心的数字-v4.mp4`
